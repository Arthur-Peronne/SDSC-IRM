## Hypothesis
This is the campaign's first trial (no champion to branch from), so it doubles as the
reference point AND a deliberate first candidate rather than a bare no-op. The judge is
now downstream classification accuracy (logistic regression on 20-d AE latents, 100
train / 20 val patients), not AE reconstruction R2. With only 100 training patients and
a fairly deep separable-residual 3D encoder, the AE can plausibly overfit the training
patients' individual anatomy into the latent code — which helps reconstruction R2 but
can hurt the *generalization* of the latent geometry that the downstream classifier
relies on for unseen validation patients. I add light L2 (weight_decay=1e-5) to keep
encoder weights from growing large/idiosyncratic, and light dropout (dropout_rate=0.1)
to discourage any single latent dimension from being a memorized shortcut, forcing more
redundant/robust structure across the 20 dimensions. I predict this increases
classification_accuracy_val relative to the fully unregularized default, at the cost of
a small amount of reconstruction R2 (logged via also_log_ae, non-decisional). Keeping
lr=5e-4 and patience=20 unchanged: lr=5e-4 was the stable/best setting in the prior
(smoke-test) campaign at this architecture, and patience=20 already allows a real
early-stopping search within the 200-epoch cap, so I'm not conflating this trial's
regularization test with an unrelated optimizer-schedule change. noise_std stays 0.0 -
denoising is a distinct mechanism reserved for a later trial if this one doesn't clearly
help, to keep this first change interpretable.

## Training Dynamics
All 3 seeds trained smoothly: no NaNs, no loss spikes, val loss decreased with the usual
noisy-but-monotonic pattern before early stopping. Early stopping triggered well inside
the 200-epoch budget in all 3 runs — seed0 at epoch 61 (best=41), seed1 at epoch 67
(best=47), seed2 at epoch 52 (best=32) — so `patience=20` is not obviously starving
convergence here; the model plateaus in the 30-50 epoch range for this config. Val
reconstruction R2 ranged 0.655-0.748 across seeds (mean 0.707), a healthy level given the
light regularization added, i.e. dropout=0.1/weight_decay=1e-5 are not aggressive enough
to visibly hurt reconstruction fidelity. Classification accuracy per seed was fairly
tight (0.575-0.600, mean 0.5917) — a smaller relative spread than the R2 seed variance,
though this is only 3 seeds, not enough to generalize a noise-floor estimate for the
classification metric yet. 59% mean accuracy on the 5-class ACDC group task is well above
the 20% chance level, confirming the 20-d latent code carries real class-discriminative
signal even under this first HP choice.

## Conclusion
This is the campaign's root trial (no champion existed), so BASELINE is a mechanical
label, not evidence against the regularization hypothesis. What the run does show: light
regularization (weight_decay=1e-5, dropout_rate=0.1) is a stable, non-destabilizing
starting point — training converges cleanly for all 3 seeds, reconstruction quality stays
healthy (R2~0.71), and classification accuracy (~59%) is comfortably above chance with
tight seed-to-seed variance. I cannot yet isolate whether the regularization itself
*helped* (that needs an unregularized ablation, which the 3-trial budget does not allow
cleanly) — but nothing here contradicts the hypothesis, and there's no sign that
dropout=0.1/weight_decay=1e-5 is already too strong (R2 didn't collapse). For trial 2, I
will keep this configuration (proven stable) and add the other main generalization lever
not yet tested — denoising via `noise_std` — to see if it lifts classification accuracy
further on top of the current regularization. That result will decide whether trial 3
keeps/strengthens noise or instead pushes harder on weight_decay/dropout alone.
