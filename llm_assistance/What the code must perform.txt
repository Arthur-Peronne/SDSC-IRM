## 3. Image registration
*Currently: `run_registration.py`*

### 3.1 Resampling (all patients and corresponding masks)
**Parameters:**
- Option: only ED, or ED+ES files (default ED+ES)
- Option: resampling target_spacing *(IN MM?)*

**Actions:**
- Load nii from original patients
- Resample patient image and corresponding mask(s) with SimpleITK
- Convert resampled patient and corresponding mask(s) as nii file
- Save resampled nii files

**Returns:** Each resampled nii (image and mask) saved in `processed_images/resampled_files`

### 3.2 Cropping
**Parameters:**
- Option: only ED, or ED+ES files (default ED+ES)
- Option: cropping window (default (128, 128, 32))

**Actions:**
- Take each resampled nii file in `processed_images/resampled` folder
- Find centroid from mask
- Crop around centroid (nii → fdata → nii) for image and corresponding mask
- Save cropped nii files

**Returns:** Each cropped nii (image and mask) saved in `processed_images/cropped_files`

### 3.3 Registration
*Uses both cropped frames (for registration calculation) and resampled frames (to perform registration on them and then crop them, to keep corners)*

**Parameters:**
- Reference patient and frame: default 001 and ED
- Option: only ED or ED+ES files *(currently no option, everything in cropped frames folder)*
- Uses cropping window (same as cropping function) to re-crop

**Actions:**
- Load image and mask, resampled and cropped frames
- Calculate the rigid transformation from the binary cropped mask, compared to the reference
- Perform rigid registration of the resampled image and mask
- Crop registered image and mask to reference window
- Save registered+cropped image and mask nii files

**Returns:** Each registered+cropped nii (image and mask) saved in `processed_images/registered_files`

### 3.4 Checks registration
*Currently: `run_registration_pipelinechecks.py`*

**Parameters:**
- ED or ED+ES files
- Checks on resampling/cropping/registering ON/OFF for each
- Option to do DICE checks
- Option to identify the n worst DICE variations

**Actions:**
- For every patient, check shape and spacing for resampled, cropped, and registered images and masks
- For every patient, calculate DICE for registered images (compared to ref)
- Stats: find patients with worst DICE. Calculate DICE stats (before/after registration, etc.)

**Returns:**
- Console prints of checks for every patient (shape, etc.)
- `.txt` file of DICE stats before/after registration

## 7. Regression
*Currently: `run_regression.py`*

### 7.1 From PCA results
**Parameters:**
- Y_name: for logistic (group, binary or not) or linear (height or weight) regression
- Source:
  - Image folder (for X data)
  - pca_folder (to load PCA results, create Y_pca)
  - Type of image (image, mask, bin or not) → *partially redundant?*
  - cumvar_threshold (how many dimensions to keep for this cumulative variance). Possibility to add a cumvar_threshold_list to run the pipeline for various values
  - splitname *(for now test_size=50 and train_size=100, hardcoded → to change?)*

**Actions:**
- Load X and Y files (train and test)
- Load PCA, calculate X_pca (dimension reduced) train and test based on n_pca from cumulative variance wanted
- Do logistic/linear regression on X_pca and Y, calculate metrics
- Plot regression results:
  - Metrics (precision, recall, accuracy for binary/multiclass; R² for linear) as a function of n_pca
  - Confusion matrix for multiclass regression
  - Scatter plot true/predicted for linear regression

**Returns:**
- Metric results logged in MLflow
- Plots in `results/`
